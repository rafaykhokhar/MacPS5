# Contributing

Read AGENTS.md and rust/README.md. Implement new runtime, CPU and verification work in Rust; Metal shader code may use Metal Shading Language. Keep guest memory guarded, resource use bounded and unsupported behavior explicit.

Run the build, tests and Clippy commands in docs/BUILD.md. Native instruction or platform changes also need focused execution checks. Distinguish compilation, fixture results, homebrew startup and actual gameplay in every report. Do not advance a progress checkpoint without evidence at that checkpoint's stated scope.

Do not commit game binaries, firmware, keys, credentials, build output or private machine data. Retain source attribution and applicable third-party license notices.
